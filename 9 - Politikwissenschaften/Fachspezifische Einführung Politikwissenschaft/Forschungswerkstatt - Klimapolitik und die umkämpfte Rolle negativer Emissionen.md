# Lecture Notes

### Overshoot Methoden

Es ist fragwürdig, ob technische CO2-Entnahme-Methoden so weit skaliert werden können und so effektiv sind, dass die Notwendigen Mengen an CO2 aus der Luft entfernt werden können. 

Außerdem lassen sich bereits eingetroffene Auswirkungen des Klimawandels nicht mehr vollständig umkehren (z.b. steigende Meeresspielgel oder Ökosysteme wie Korallen)

Overshoot Methoden wie CDR (Carbon Dioxide Removal) werden vor allem deswegen ins Gespräch gebracht, da sie aufgrund verpasster Umsetzung von Maßnahmen zu früheren Zeitpunkten nun als die einzige theoretische Möglichkeit erscheinen, die Klimaziele noch einzuhalten. Ihre praktische Anwendbarkeit bleibt aber fragwürdig. Diese wären bei der Reduktion von Emissionen auf Netto Null den restlichen Überschuss an Emissionen, den bereits in der Luft ist, zu entfernen.

Problem: Die Erwartung, dass Technologien wie CDR aufgrund neuerer Verfahren in der Zukunft so effizient werden, dass im hier und jetzt keine oder weniger klimapolitische Maßnahmen notwendig sind (mitigation deterrence).

-> Emissionen können auch auf der Nachfrage Seite reduziert werden. -> Mitigation Policies. Was für individuelle Maßnahmen können getroffen werden, um den Ausstoß von Emissionen zu verringern. 

3 Verschiedene Ansatzpunkte zur Vermeidung von Emissionen (mit Beispielen anhand von Mobilität):
- Avoid: Auf emissionserzeugendes Verhalten wird verzichtet (Verzicht auf Mobilität)
- Shift: Umweltfreundlichere Alternative werden gewählt (Public Transport, Walking, Cycling, etc.)
- Improve: Emissionseffizienz bekannter Methoden wird verbessert (Effizientere Treibstoffe, Elektromobilität)

Erkenntnis: Avoid-Ansätze werden von existierenden mitigation policies weitgehend ignoriert.
