#### Strange behavior of 'Expressions' and 'Participant state' columns in CRF Editor
location: CRF Editor > Column view > '4. CRFs' tab > 'Expressions' + 'Participant state' columns

This issue seems to be related to CSNG-85

The issue of columns vanishing if the data grid width is reduced due to them having no minimal width seems to persist for the Column view only.

Strangely, however, this only occurs in certain situations. It seems that the trigger for whether the columns have a minimal width or not depends on the current width of the data grid at the moment the corresponding tab (4. CRFs) is selected. (see screen capture)
#### Column / Row View tooltips improvement
location: CRF Editor

Currently, only the tooltip of the view mode that is currently not active can be displayed (see screen capture). I think it would make sense that both tooltips can be displayed all times, so that the user doesn't need to switch view modes first before being able to see the other tooltip.

#### Height of activate/deactivate user dialog cannot be changed properly
location: Access management > Users > activate/deactivate user

Changing the width of either the activate or deactivate user dialog works as intended. Changing the height, however, instead leads to the dialog being pushed around the screen (upwards instead of decreasing the height and downwards instead of increasing the height) (see screen capture). After pushing the dialog downwards a bit, the dialog height will eventually increase. Decreasing it (beyond the initial size), however, isn't possible at all.
