## Solved Problems & Learnings

### 1. Data Grid Filter State Collision
* **Issue:** The 'Country' column filter is overridden or ignored when a third filter is applied (e.g., toggling active status or entering text in the site/email columns).
* **Insight:** This indicates a state synchronization issue within the data grid's filter-reducing logic, where certain action dispatches inadvertently flush or overwrite existing filter criteria instead of appending them.

### 2. Focus Retention & Hover Highlight Bug
* **Issue:** The action column cell in the data grid fails to highlight on hover after an action button (e.g., View/Edit) is clicked.
* **Insight:** The button within the action column retains active focus even after the modal closes. This prevents the CSS `:hover` state of the parent cell/row from rendering correctly. The focus state needs to be programmatically cleared or returned to the grid container upon modal closure.

### 3. ItemCombobox Component Deficiencies
* **Keyboard Navigation (Accessibility):** The custom `ItemCombobox` is skipped during Tab navigation if no value is selected. If a value is selected, focus shifts to the clear ('x') button rather than the input field, preventing keyboard-only selection changes.
* **Responsiveness:** The component lacks flexible width styling, causing it to overflow or fail to scale when its parent modal is resized.
* **State Styling:** The component lacks read-only/disabled visual cues (e.g., a darker background) when rendered in view-only mode.
* **Rendering Bug:** In the CRF Editor Form Preview, the component fails to bind and display the placeholder or selected value text.

### 4. Localization & Content Regressions
* Identified several hardcoded test strings (e.g., "Sexxxx", "Male1111") and unparsed translation keys (e.g., `participant_dialog.participants`) in the Participant Management module that need to be cleaned up and integrated with the localization provider.
