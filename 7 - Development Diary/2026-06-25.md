Following is a list of new tickets / assessed tickets that need improvements:
# Strange behavior of 'Country' column filter in data grid
Filtering via the country columns now generally works, but the issue of the filter being overwritten in case a third filter is applied still persists.

Interestingly, this only seems to apply to some filter options. In the attached screen capture, for example, the data grid is filtered via "Is this a training site?" = "Yes" and "Country" = "Portugal", which results in only a single row being displayed. Selecting "Should this site be active?" = "No" correctly shows zero results. Selecting "Should this site be active?" = "Yes", however, results in the Country filter being completely ignored and all results matching the other two filters being displayed.  
The same is the case for other columns, for example, if a digit is typed into the Site number column or a letter into the e-Mail column (see screen capture)

# Action column of the selected row is not highlighted after an action button has been pressed
location: data grid

Usually, a whole row would be highlighted on hover. However, when pressing one of the buttons within the action column, this specific cell of the corresponding row will not be highlighted afterwards (see screen capture)

It seems that this is the case because the button within the action column stays selected, after being pressed, even when the View/Edit/... Form has been closed again. This becomes noticeable when using tab to navigate through the data grid (see screen capture). So the problem seems to be that a cell from the action columns becomes un-highlighted if one of its action buttons is currently selected
